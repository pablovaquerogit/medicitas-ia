# Seguridad y privacidad

- Los blueprints de este repositorio fueron sanitizados.
- No se incluyen tokens, claves de API, credenciales ni webhooks activos.
- No se publican identificadores reales de Google Sheets, Google Calendar o grupos de Telegram.
- La base de datos incluida utiliza únicamente personas, teléfonos, correos e identificadores ficticios.
- No deben almacenarse datos reales de pacientes en un repositorio público.
- Los secretos deben configurarse directamente en Make o mediante un gestor seguro.
- Antes de cada publicación, busca correos, teléfonos, IDs, tokens y archivos de credenciales.
- Este proyecto no acredita cumplimiento de normas clínicas o de privacidad.
